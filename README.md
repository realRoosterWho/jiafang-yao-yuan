# 甲方要圆

你是地球上手艺最好的工匠，被外星甲方绑回了母星。甲方只有一个需求：所有东西都得是圆的。

一个单文件的 2D 敲击小游戏：拎起材料往地板上砸，把它砸圆。一共 49 单：前 21 单是冒险模式（`index.html` 里的 `ADVENTURE`，每种花样一单，新机制第一次出现时有说明卡），后面是剩下的关卡（`ORDER` 里其余的，按原来的先后）。订单簿也分这两档。

直接打开 `index.html` 就能玩，没有构建步骤。

## 界面素材（`ui-crispkit` 分支）

这个分支是一套休闲宇宙风的界面：夜空背景图 + `casual_space_ui_kit` 素材包。玩法没动；`main` 上还是原来的样子。

**素材从哪来**

- **背景**：一张夜空图（带环的行星、两个底角的云和小星星、顶上两角的叶子、一格一格的地砖），WebP 内嵌成 base64（`BG`，约 55KB）。游戏还是单文件，服务器不用多发文件。要换图只换那一行；图是 16:9 的，地平线大约在 78% 高。
- **`casual_space_ui_kit`**（`SK_SVG`，名字都以 `s` 开头，约 10KB）是主体：按钮、图标按钮、弹窗、订单卡、舷窗、进度填充、力度计、心、星、金币、小标签、提示条、星球和云。每件只留图形，共用一份渐变 / 投影定义（`SK_DEFS`）。素材里写死的字都去掉了，字由游戏自己写，中英文都能放。
- **CrispKit**（`KIT_SVG`）只留那套里没有的几样：订单簿的关卡格、卡片里的内嵌面板和输入框、小圆章、按键图标、对勾，改色成同一套金 / 绿 / 奶油色（`kitTint`）。授权：可以用在游戏里、可以改色，但不能把素材单独拿出来再分发，所以别把整个素材包提交进仓库。
- 开局时 `kitBoot` 把每件素材塞进 CSS 变量 `--k-名字`，画布上要用的再栅格化一份。画布上 `kit(名字, x, y, w, h)` 整张贴，`kit9(…)` 九宫格贴。
- **按钮和弹窗不用 `border-image`**：屏幕缩放是 125% 这种非整数时，九宫格的块和块之间会露一条细缝。现在把图切成几块各当一层背景（按钮三块、弹窗九块），中间的块往两头底下多伸一点，不露缝。

**排布**（照排布参考图；电脑和手机分开排）

- **任务区（左上）**：舷窗、气泡、订单卡挨在一起算一块。电脑上订单卡竖着挂在舷窗下面，跟舷窗一样宽；手机上横过来铺成一条。气泡从舷窗的右下冒出来。
- **目标栏（顶上居中）**：「有多圆」、圆度条、读数并成一条紫色的长药丸，中线对着料（x = 440）。上沿骑一块小牌子「目标 ★ 78%」，只突出下一颗星那条线，另外两条星线只留淡淡的刻痕。下面一行只有耐久的心和现在够几颗星。材料名、敲击统计不在顶上重复（气泡、接单卡、结算卡里有）。
- **右边**：回首页在右上角，力度计在它下面一直到地板线。
- **底部一条控制带**：左边声音、重来两个图标按钮，中间轮换的提示条，右边交货，上下对在同一条线上。舞台下面原来那行说明收掉了（`#help`），不要两层说明。
- **对齐**：四边留一样的边距（电脑 14、手机 8）。左边舷窗、订单卡、声音按钮齐；右边回首页和力度计齐；上边小牌子和回首页齐。
- **手机竖屏**：顶栏是小号舷窗 + 目标栏 + 右上角的回首页，下面一条横的订单卡；力度表横在底部；图标按钮放大到至少 44 像素、没有快捷键的小键帽；卡片里的按钮加高、一行两个。背景图竖着只露中间一条，两侧用素材包的星球和云补上（`portDecor`）。

**层级**（不是所有东西都一样响）

- 最要紧的放最大：圆度读数、订单卡上的倒计时。次要的收轻：第几单、金币。
- 卡片上的按钮：往前走的那一颗（下一单、接单……）是绿的、最大；其余都小一号、统一金色。手机上大的那颗独占一行。
- 耐心快没了：倒计时变红、底下一块红光一呼一吸、沙漏抖。
- 拎着料的时候：力度表上一道白线标出此刻松手会落在哪儿，那一档的小标签（轻 / 好 / 碎）放大。
- 提示条是教操作的：第一次拎起来之前带两头的小金光，之后变淡。
- 墙上的厂训「一切皆圆」挪到右边远处，料的周围留空。

**开始界面**（封面，`drawCover` + `#startui`）

- 画布画背景、把自己砸圆的木头、标题；按钮是页面元素，都居中在一条竖线上：大的绿色按钮（没做过单是「开始」，做过了是「接着做第 N 单」），下面一排金色的（订单簿、排行榜、成就、玩法 · 存档），右下角换语言，左下角声音。
- 点大按钮、点空白处、按回车或空格走同一条路（`leaveCover`）：新玩家由 `flow.js` 接手去看开场和新手关；老玩家直接到该做的那一单；没有进度又没开开场流程的，先到原来那张首页卡片看玩法。别的键在这里不起作用（Tab 要能走到按钮上；`flow.js` 对新玩家仍然是按任意键开始）。
- 新玩家签合同之前只留大按钮和换语言（`flow.js` 自己放的 `#flow-lang`，这里只给它换了皮），其余按钮收起来。这一次打开以后只要离开过开始界面（`#stage.seen`），再回来就全给。
- **开始界面就是首页**（`goHome`）：游戏里右上角的回首页、各张卡片上的「回首页」、Esc 都回到这里，回来时局面摆回第一单、三星光效关掉。换完语言也回到这里。
- 原来那张首页卡片（玩法说明、存档名、重看开场）从「玩法 · 存档」进，上面多了一个「返回」，按 Esc 也能关。

**效果**

- **彩虹进度条**：圆度条没到一星是金色的填充，带慢慢流的斜纹；够一星以后变成一道流动的彩虹，往外放光，有一道光扫过去，旁边闪小星星，星级越高越亮（`kitBar`）。
- **三星光效**：三颗星到手以后，画面四周一圈流动的彩虹光（`drawEdgeGlow`），舞台外面也泛一圈光（`#stage.star3`）。
- **手感**（`juiceWatch` + `J`）：不改玩法，只看每帧的状态变没变。砸中了落点冒小星星、舷窗鼓一下；圆度涨了读数弹一下；多了一颗星那颗星从小弹到大；砸过头掉的那颗心抖一下；按钮碰一下往上弹。
- **击打评价**（`drawJudge`）：照音游的做法，不要气泡、不要数字，就一个词在料的头顶弹出来：太轻（蓝）、轻磨 / 好（绿）、重击（金，最大）、过重（红）；这一下反而砸得更不圆了，同样的词用暗一点的土黄。玩法那边照旧往飘字里塞「太轻 12」「重击 62」「压扁了！」「太重 70 > 64」，画的时候认出来换个画法：数字去掉；砸过头统一写「过重」，材料自己的那句缩成一行小字跟在下面；「太重 70 > 64」那行不画（力度表上会闪「太重！」）。新的评价一出来，上一个马上淡掉。别的飘字（露出硬壳了、变硬 → 70、★★★）照旧。
- **夜空**（`skyFx`）：时不时有一颗流星斜着划过去（两条节奏不一样的轨道，各隔 6 秒和 10 秒左右放一颗，有时空一轮），另有几颗星星一明一暗。开始界面和游戏里都有。位置和方向全靠时间算出来，不存状态。
- 系统开了「减少动态效果」时，上面这些只留静止的样子。

**CSS 怎么改的**：原来的规则一条没删，`<style>` 末尾加了一段「休闲宇宙风界面」只盖外观。卡片里把颜色变量换成奶油底深棕字那一套；舞台上（深色底）的变量没动，`flow.js` 也在用。

**没换的**：甲方本人（表情要跟着心情变）、材料贴图、「交货！」的盖章演出，以及 `flow.js` 里的占位片、新手关和合同。素材包里没用上的：平台底座、设置 / 暂停 / 播放图标、绿色和红色的进度填充、粉色和蓝色的按钮、击打气泡、叶子、带字的示例图。

## 星级和成就

- **星级**：★★★ 就是每单的达标线；★★、★ 各往下让 3、6 个点（起始圆度离达标线很近的单让得少，见 `starLines`），够一星就能交货，时间到了也按当时的星级自动交。没到三星线的酬劳按离一星线多远打折，一星线上是 ×0.6。有星级以前交付过的单一律算三星。
- **成就**：定义表是 `index.html` 里的 `ACH`，分「现场 / 进度 / 手艺 / 坚持 / 怪癖」五组。进度类（有 `goal`/`prog`）从存档就能算，老玩家第一次打开会补发；其余由游戏里的事件触发（`achRound` 在每单结束时统一结算，单局里的在 `impact`、`release` 等处直接 `achUnlock`）。本地存在 `localStorage` 的 `yuan.ach.v1`。

## 开场流程（flow.js）

新玩家第一次点开封面，走的是：**播片 → 新手关 → 甲方递合同 → 签名 → 选去处**。整套流程都在 `flow.js` 里，`index.html` 只多了三行（递出几个内部函数的 `window.__yuanFlow`，和末尾的 `<script src="flow.js">`），所以别的分支改 `index.html` 基本不会跟它冲突。

- **播片**：现在是 5 秒以内的占位动画，可以跳过。片子做好以后把地址填进 `flow.js` 顶上的 `CONFIG.video` 就接上了；放完、放不出来、或 5 秒还没开始播，都会自动往下走。`collector.py` 只发 `STATIC` 里列出的文件、也不支持 Range，视频建议放到别处（CDN / 对象存储）再填完整地址。
- **新手关**：一块只有一个凸起的石头，砸不碎、不计时、不上报、不进存档。电脑上提示按住 A / D 旋转，手机上提示第二根手指左右滑。凸起朝下砸一下就过线，砸在圆的那面只会蹭掉一点，不会越砸越糟。参数在 `TUT` 里。
- **合同**：过关后甲方说「做得不错，我们决定雇你」，递过来一张劳务合同，第四条写明完不成任务乙方本人被做成圆形。签名调用的就是原来的起名字存档（`setName` → `/api/save`）；离线打开或服务器连不上时先记在本机。
- **签完以后**：「下一关」（最大的按钮）进第 1 单，「去收藏室选关」现在进的是订单簿，换目标改 `CONFIG.collectionAct`。
- 老玩家（本机有进度，或已经签过合同）点封面还是直接进首页；首页右下角有「重看开场和新手关」。
- 进度记在 `localStorage` 的 `yuan.flow.v1`。调试：`?intro=1` 强制走一遍，`?intro=0` 关掉。
- 不想要这套流程：删掉 `index.html` 末尾的 `<script src="flow.js">`，游戏就回到原来的「封面 → 首页」。`flow.js` 加载失败时也是这样。

## 线上版本和玩家数据

- 游戏：<https://fullcircle.roosterwho.com/>（roosterpi 上的 `fullcircle.service`，Cloudflare Tunnel `fullcircle` 对外）
- 数据后台：<https://fullcircle.roosterwho.com/admin>，团队密码在 roosterpi 的 `~/services/fullcircle/admin.env`
- 游戏会匿名上报每一单的开工、交付、失败、中途关掉（随机玩家 ID，不存 IP）。本地打开不上报。
- 云存档：玩家在首页可以起个名字，每单最高酬劳、最高星数和解锁的成就会存到服务器，换设备输同一个名字就能接着玩。没有密码，服务器合并时酬劳和星数按每单取较大值、成就取并集，所以同名只会让成绩变高、抹不掉进度；后台「存档玩家」里能看到并删掉不合适的名字。星级和成就存在 `saves` 表的 `extra` 列（JSON），老库启动时自动加列。
- 服务端代码在 `server/`：`collector.py` 收事件写 SQLite，`saves.py` 是云存档，`admin.py` + `admin.html` 是后台。

**部署是自动的**：`main` 上的 HEAD 一变，并且这次变化碰了 `index.html`、`flow.js` 或 `server/`，钩子就在后台把 HEAD（不是工作区）部署到 roosterpi：

- 直接提交、`--amend`（`post-commit`）
- 合并分支、`git pull`，包括快进合并（`post-merge`）
- `git rebase`、`git pull --rebase`（`post-rewrite`）

在别的分支或 worktree 上提交不会部署，合并进 `main` 才会。日志在 `.git/deploy.log`，部署失败会弹 macOS 通知。新 clone 要先启用钩子：

```bash
git config core.hooksPath .githooks
```

手动部署：`server/deploy.sh`；跳过一次自动部署：`FC_NO_DEPLOY=1 git commit ...`。终端里看汇总：`ssh roosterpi 'cd ~/services/fullcircle && python3 collector.py report'`。
